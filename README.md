# AutoSense AI - Predictive Maintenance System



## Project Overview



AutoSense AI is an end-to-end Machine Learning application that predicts machine failures before they occur.



The project includes:



\- Data Cleaning \& EDA

\- Feature Engineering

\- Machine Learning Models

&#x20; - Logistic Regression

&#x20; - Random Forest

&#x20; - XGBoost

&#x20; - LightGBM

\- SHAP Explainability

\- FastAPI Backend

\- Streamlit Dashboard
